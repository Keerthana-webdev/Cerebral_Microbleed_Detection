# Cerebral Microbleed Detection Using Deep Learning

## Project

A deep learning-based system for detection and localization of cerebral
microbleeds from brain MRI/SWI scans.

## Pipeline

MRI/SWI
→ Preprocessing
→ Candidate Detection
→ Mimic-Aware Classification
→ Confidence Scoring
→ Severity Grading
→ Grad-CAM
→ Diagnostic Report
→ Clinician Dashboard

## Dataset

VALDO Task 2

## Framework

Python + PyTorch + MONAI

## Application

Streamlit
